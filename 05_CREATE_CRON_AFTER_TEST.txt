LELLEE — CREATE CRON ONLY AFTER MANUAL RUN PASSES

After the one-task manual RUN returns processed=1 and SQL verification shows:
  task_status = needs_review
  latest_run_status = completed
  review_status = pending

Then:

Supabase -> Integrations -> Cron -> Create job

Choose:
  Supabase Edge Function

Function:
  dynamic-worker

Method:
  POST

Body:
  {"mode":"run","limit":3}

Header:
  x-lellee-agent-worker-secret: [same LELLEE_AGENT_WORKER_SECRET]

Schedule recommendation while building:
  every 15 minutes

Later, once the queue is stable, change the schedule if needed.

Never put the OpenAI API key in the Cron body/header. The OpenAI key belongs
only in Supabase Edge Function Secrets.
